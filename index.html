How I architect

Tools change every release. These principles don't, and they shape every engagement I lead.

  1. Platform before projectsEnvironment strategy, DLP, identity and a CoE come first, so the tenth app is as safe as the first.
  2. Right tool, not favourite toolCanvas, model-driven, code apps, Power Pages or plain Azure. The requirement picks, not habit.
  3. Integration by contractAPIs behind API Management, custom connectors and events with an outbox, never point-to-point spaghetti.
  4. Secure and governed by defaultLeast privilege, Entra ID groups, managed environments and audit, designed in rather than bolted on.
  5. Built for the team that runs itSolutions in source control, automated quality gates, and documentation the support team actually reads.
  6. AI with guardrailsAgents grounded on approved knowledge, with humans in the loop for anything that changes data.
